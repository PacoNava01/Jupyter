# 🏛️ Bóveda de Aprendizaje: Python & Computo Científico
### Por: Francisco Nava Valencia | [Ciencias UNAM](mailto:francisconavavalencia@ciencias.unam.mx)

Este repositorio es mi almacén personal de código y recursos desarrollado durante mi formación en el manejo de `Python` y `Jupyter Notebooks`. El objetivo principal es documentar el dominio de herramientas aplicadas a **microcontroladores, sensores y actuadores**.

> [!TIP]
> **Propósito Didáctico:** Este espacio sirve de apoyo para cualquier persona que, como yo, esté iniciando en el uso de herramientas básicas de cómputo científico. ¡Eres libre de explorar y aprender!

---

## 🛠️ Herramientas y Tecnologías
* **Lenguajes:** `Python 3.x`
* **Entornos:** `VS Code`, `Jupyter Lab (Anaconda)`
* **Hardware en la mira:** Microcontroladores, Sensores de proximidad, Actuadores.
* **Librerías clave:** `NumPy`, `Matplotlib`, `OpenCV` (Próximamente).

## 📂 Estructura del Repositorio
| Carpeta / Archivo | Descripción |
| :--- | :--- |
| `notebooks/` | Experimentos y explicaciones paso a paso en Jupyter. |
| `scripts/` | Archivos `.py` listos para ejecución directa. |
| `docs/` | Diagramas de conexiones y guías teóricas. |
| `README.md` | Guía principal del repositorio (este archivo). |
